# Changelog

## 0.1.3-beta.2 — FileGlance Beta 2

- Hover cards show the file type and last modified time alongside the name and size, even when a thumbnail is unavailable.
- Unknown extensions are shown as format labels. Files without extensions also get a summary.
- Finder packages, including macOS apps, show their type and last modified time. The card omits the size because a package is stored as a directory.
- Existing previews for images, PDF first pages, and plain text remain available, with Quick Look thumbnails or file icons for other formats.

## 0.1.2-beta.1 — FileGlance Beta 1

- Improved file detection in Finder and on the desktop when Finder does not expose a direct file URL.
- Allowed small pointer movements during the hover delay.
- Documented how to renew Accessibility access when an older copy still holds the permission.
